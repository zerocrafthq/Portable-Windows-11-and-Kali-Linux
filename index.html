Dual-Boot Portable Windows 11 & Kali Linux on an External M.2 SSD

A complete, risk-free, step-by-step guide to running a fully functional Portable Windows 11 (Windows To Go) and a dedicated Kali Linux installation on a single external M.2 NVMe SSD. Your host PC's internal drive is never modified — plug the external SSD into almost any PC to boot either OS.

📋 Prerequisites & Hardware Requirements

  • External M.2 NVMe SSD (256 GB minimum recommended; e.g., 150 GB for Windows + 100 GB for Kali).
  • High-Speed USB Enclosure: USB 3.2 Gen 2 (10Gbps) or Type-C NVMe enclosure to avoid bottlenecks.
  • 1x Separate USB Flash Drive (8 GB or larger) for Kali installer media.
  • Host PC running Windows 11 with Secure Boot disabled in BIOS.
  • Software Downloads:
    • Windows 11 ISO
    • Kali Linux Installer ISO
    • Rufus (Portable recommended)

Step 1: Flash Portable Windows 11 to the External M.2 SSD

⚠️ WARNING: This will erase everything on your external M.2 SSD.
  1. Connect your external M.2 SSD via USB.
  2. Open Rufus.
  3. Enable Show advanced drive properties and check List USB Hard Drives so the M.2 SSD appears.
  4. Select your external M.2 SSD under Device.
  5. Click SELECT and choose your Windows 11 ISO.
  6. Change Image option to Windows To Go.
  7. Ensure Partition scheme = GPT and Target system = UEFI (non CSM).
  8. Click START.
  9. When prompted, choose your Windows edition (e.g., Windows 11 Pro).
  10. In the final warning, check Prevent Windows To Go from accessing internal disks and click OK.
  11. Wait for Rufus to finish (status shows READY).

Step 2: Shrink the External Drive to Create Space for Linux

  1. Right-click Start → Disk Management.
  2. Locate your external M.2 SSD (verify by total size).
  3. Right-click the large NTFS partition and choose Shrink Volume.
  4. Enter the space for Kali in MB (e.g., 102400 for ~100 GB) and click Shrink.
  5. You should now see an Unallocated black block next to the Windows partition. Close Disk Management.

Step 3: Prepare the Kali Linux Installer USB

  1. Plug in your separate 8 GB+ USB flash drive.
  2. Open Rufus and select the USB flash drive (not your M.2 SSD).
  3. Click SELECT → choose the Kali Linux Installer ISO.
  4. Click START. If asked to download syslinux files, click Yes. Choose Write in ISO Image mode if prompted.
  5. Wait for Rufus. Keep both the external M.2 SSD and Kali USB plugged in.
  6. Restart the PC, press your BIOS boot key (F2, F12, Del, Esc), ensure Secure Boot is disabled, and boot the Kali USB. Choose Graphical install.

Step 4: Install Kali Linux Into the External SSD Free Space

  1. Follow Kali installation prompts (Language, Location, Keyboard, User, Timezone).
  2. At Partition disks:
    • Select Guided - use the largest continuous free space.
    • CRITICAL CHECK: Ensure the installer selects your external M.2 SSD (verify size/model) and NOT your internal drive (e.g., /dev/nvme0n1).
    • Choose All files in one partition (recommended for new users).
    • Select Finish partitioning and write changes to disk, confirm Yes.
  3. On Software selection, keep defaults (Xfce and standard tools).
  4. When finished, keep the USB plugged in, reboot, and use your Boot Menu key to boot into Kali on the external SSD.

Step 5: Configure Universal EFI Bootloader (GRUB Removable Mode)

To boot on any computer without relying on host NVRAM and to provide a single GRUB menu for both OSes, run the following on Kali (adjust partition names as needed):

# Update package lists and install required utilities
sudo apt update && sudo apt install -y grub-efi-amd64-signed shim-signed

# Identify your external SSD's EFI partition (example)
sudo lsblk

# Mount partitions as needed, then install GRUB in removable mode:
sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=kali --removable

# Update GRUB to detect Portable Windows and other entries:
sudo update-grub

Tip: If Windows doesn't appear in GRUB, mount the Windows partition (e.g., sudo mkdir -p /mnt/win && sudo mount /dev/sdx1 /mnt/win) and re-run sudo update-grub.

💡 Troubleshooting & Tips

  • Host Internal Drive Protection: Because you checked "Prevent Windows To Go from accessing internal disks" earlier, the host internal drive stays isolated.
  • Time Desync Between Windows & Linux: If the clock shifts when switching OSes, run on Kali: 
    timedatectl set-local-rtc 1 --adjust-system-clock
  • Wi-Fi Not Working in Kali? Many laptop Wi‑Fi chips require proprietary firmware; consider an external USB Wi‑Fi adapter (e.g., Alfa AWUS036ACS) if internal card drivers are unavailable.
